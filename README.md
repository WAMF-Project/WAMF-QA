# WAMF-QA

Quality assurance, testing datasets, and validation tools for WAMF (Who's At My Feeder).

This repository contains test media, expected results, validation workflows, and regression testing resources used to verify WAMF releases.

## Planned Contents

* Test Video Suite
* Species Validation Dataset
* Regression Testing Tools
* Frigate Compatibility Testing
* Performance Benchmarking
* Release Validation Workflows

## Goals

* Ensure repeatable testing
* Detect regressions before release
* Validate new WAMF features
* Verify compatibility with supported Frigate versions

## Related Repositories

* WAMF
* WAMF-Docs

WAMF-QA helps ensure WAMF releases remain reliable, accurate, and predictable across future versions.


## QA Tools

* [MediaMTX Test Feed](mediamtx-test-feed/README.md) — publish local test videos to the fixed Frigate/WAMF RTSP test path using a small Dockerised UI.
